# Repository audit protocol

The 16-candidate registry was fixed on 2026-08-08 from the WorldLens ecosystem and a public world-model discovery list, with official paper/project sources used to verify identity. Eligibility requires a peer-reviewed or formally accepted 2023–2026 driving or embodied-navigation world-model paper, an official revision-pinned public repository, and a substantive readable inference, sampling, or evaluation entry point. Distributed support is coded after inclusion, not used to determine eligibility.

Prior exposure is retained in the registry: positive paths in DriveDreamer, OpenDWM, and DriveLaW had already been inspected; Drive-WM, Vista, and DrivingWorld had also received earlier code or README inspection. This is a purposive multi-case sample, not an unbiased prevalence estimate or a fully blind discovery study.

For each eligible repository, the audit records revision, license, entry point, distribution, sharding, random-stream binding, failure semantics, reduction, and topology tests. A positive signal requires a revision, file, and locator. Unresolved evidence remains unknown. Static signals are not treated as executed original-model defects.
